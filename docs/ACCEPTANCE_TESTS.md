# 验收测试清单

## 玩家
- [ ] WASD 四方向移动正常，斜向移动速度不会额外变快。
- [ ] 鼠标在玩家周围移动时，瞄准方向正确。
- [ ] 玩家不会穿过配置了碰撞体的墙。
- [ ] 闪避有冷却，不会无限连续触发（闪避阶段实现后检查）。

## 武器与子弹
- [ ] 点击射击后，子弹沿瞄准方向移动。
- [ ] 子弹只对有效敌人造成一次伤害。
- [ ] 子弹离开有效范围后销毁或回收到对象池。
- [ ] 射速可在 Inspector 调整。
- [ ] 暂停时子弹停止移动。
- [ ] 子弹不会命中玩家自身。

## 敌人
- [ ] 敌人追击玩家，不会在攻击距离外造成伤害。
- [ ] 敌人攻击存在冷却。
- [ ] 敌人死亡只掉落一次经验。
- [ ] 多个敌人同时存在时没有明显错误或异常卡顿。

## 升级
- [ ] 经验值正确累积。
- [ ] 升级时游戏暂停。
- [ ] 三个升级选项不重复（可用升级不足时除外）。
- [ ] 选择升级后属性确实改变。
- [ ] 关闭升级界面后游戏恢复运行。

## 游戏流程
- [ ] 主菜单可以开始游戏。
- [ ] Esc 暂停和恢复正常。
- [ ] 玩家死亡后显示失败界面。
- [ ] 胜利后显示结算界面。
- [ ] 重开后生命、经验、升级、敌人和波次都重置。

## 美术与 UI
- [ ] 玩家与敌人轮廓容易区分。
- [ ] 玩家子弹与敌方子弹颜色明显不同。
- [ ] UI 在 16:9 与窗口缩放时没有关键元素被裁切。
- [ ] 文字大小在常见桌面分辨率下可读。
- [ ] 场景地面不会干扰敌人和子弹辨识。

## 构建
- [ ] Unity Console 没有编译错误。
- [ ] Windows 构建可以启动。
- [ ] 从菜单开始、完成战斗、结算、重开流程可用。
- [ ] 构建设置中包含所需场景。
