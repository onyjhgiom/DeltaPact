# 《三角洲契约》美术资产生成提示词
用途：为 AI 图像生成、概念设计、精灵图制作提供统一风格。生成后仍需检查授权、透明背景、切图和游戏内可读性。

## A. 统一风格总提示词
高品质日系动漫动作射击游戏美术，2D 手绘与精致赛璐璐上色融合，末日科幻都市，冷白与深海军蓝为主色，青蓝色能量光，少量橙红色危险提示，轮廓清晰，强烈但克制的光影，游戏资产设计，构图清晰，适合俯视角 2D 射击游戏，角色和武器轮廓在小尺寸下仍可辨认。不要文字、不要水印、不要 logo、不要 UI 截图、不要多余肢体、不要武器穿模。

## B. 主角角色立绘（概念稿，不直接作为游戏 Sprite）
白发蓝眼的年轻成年女性战术士兵，未来科幻轻型战术服，深蓝与冷白装甲，少量青蓝发光能量模块，背负轻型战术装备，手持原创科幻突击步枪，坚毅而沉着的表情，日系动漫游戏角色设计，精致赛璐璐上色，正面全身，清晰剪影，纯色或透明背景，角色概念设计，不要文字和水印。避免过度暴露服装，强调机动性与实用战术设计。

## C. 主角 2D 游戏 Sprite 方向
为俯视角 2D 游戏制作可切分的角色 Sprite 参考：同一白发蓝眼成年女性战术角色，深蓝冷白战术服，统一比例、统一光源、统一线条粗细。需要四方向或八方向视角：上、下、左、右（可后续补对角方向），每个方向分别输出独立图，不要把多个方向拼在一张图里。透明背景，角色居中，脚下不带阴影贴图，四周留 10% 安全边距，不要文字、水印、背景、武器特效。建议先生成静态方向参考，再由美术制作待机、移动、射击、受击、死亡动画。

## D. 动画帧参考
同一角色、同一服装、同一发型、同一比例，2D 手绘动漫游戏精灵动画参考。单次只生成一种动作，透明背景，角色大小和脚底位置一致。动作选择：待机、跑步、向下射击、向左射击、受击、闪避。不要把不同动作混在一张图，不要自动加文字、边框或背景。注意：生成式图像常会出现帧间造型不一致，正式 Sprite Sheet 需要人工修整和切帧。

## E. 武器图标/横向武器精灵
原创科幻枪械游戏资产，单独一把枪，侧视图，枪口朝右，透明背景，轮廓清晰，2D 手绘动漫风，深灰金属、冷白结构、青蓝能量指示灯，适合 128–256 px 图标。分别生成：
1. AR-07 突击步枪：均衡、紧凑、模块化。
2. SG-12 霰弹枪：短枪管、厚实机匣、橙色能量标记。
3. SR-09 精准步枪：较长枪管、瞄准镜、蓝色标记。
禁止文字、数字、标识、水印；枪械为虚构游戏道具，不对应真实武器型号。

## F. 敌人 Sprite 方向
原创末日科幻敌人，适配俯视角 2D 动作射击游戏，手绘动漫风，剪影清晰，与玩家形成视觉区分，透明背景，单体居中，无地面、无文字、无水印。分开生成：
1. 近战追击者：轻型机械/变异装甲，红橙色弱点灯。
2. 远程射手：中距离攻击姿态，紫红色瞄准灯。
3. 快速突袭者：低矮、轻型、明显的高速轮廓。
4. 精英敌人：更大体型，攻击前有明显蓄能部位。
5. Boss：比普通敌人大 2–3 倍，中心有醒目的红色能量核心，轮廓不能与背景混淆。

## G. 场景 Tilemap
2D 手绘末日科幻都市地面 Tilemap，俯视角正交视图，深灰蓝沥青、破损混凝土、细小裂纹、少量青蓝科技残光，整体低对比度，不能抢过角色和子弹的视觉焦点。无透视、无文字、无角色、无车辆主体、无 UI。制作可无缝拼接的地面块，边缘必须可平铺。另行生成墙体、路障、废车和掩体的独立透明素材。

## H. 背景概念图
2D 手绘动漫末日都市，破损高楼、远处夕阳、蓝灰色烟尘、少量橙红色警示灯，电影感构图。用于菜单背景而非战斗地面，允许丰富细节。不要文字、logo、水印、UI。

## I. 战斗特效
透明背景的 2D 手绘动漫射击特效素材，单独输出：
- 青蓝色枪口闪光
- 橙色命中火花
- 蓝白色子弹轨迹
- 紫色电磁脉冲圆环
- 冰霜碎片
- 小范围火焰爆炸
- 受击闪光
每张图只包含一个特效，居中，透明背景，无文字和水印。特效要有清晰中心和柔和边缘，不要过曝到遮挡敌人。

## J. UI 图标
深海军蓝、冷白、青蓝点缀的动漫科幻游戏 UI 图标，统一线条粗细和透视，透明背景，单个图标居中。分别生成：生命、经验、弹药、装弹、闪避、技能、暂停、波次、Boss、升级。不要文字、不要数字、不要水印。

## K. 负面提示词（可按工具能力使用）
文字、乱码、签名、水印、logo、复杂背景、低清晰度、模糊轮廓、过度噪点、错误手指、额外肢体、枪械变形、角色比例变化、重复角色、拼贴边框、UI 截图、过曝粒子、与主色板冲突的高饱和随机颜色。

## L. 导入 Unity 前检查
- 精灵图需要透明 PNG，建议从 512×512 或 1024×1024 的单体图开始。
- 角色动画帧必须统一画布尺寸、缩放比例、脚底基线和朝向。
- UI 图标尽量提供 128×128 或 256×256 版本。
- Tilemap 地面块需实际平铺测试，不能只凭预览判断。
- 保留原始生成图、裁切后的 PNG 和提示词文本。
- 确认每项素材的商用许可与生成平台条款。
