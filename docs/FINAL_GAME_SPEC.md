# 《三角洲契约》最终可玩版规格

## 定位
2D 俯视角动漫科幻射击 Roguelite。PC 首版键鼠操作，后续再适配手柄与手机。强调清楚的射击反馈、短局循环和随机构筑。

## MVP 必须包含
- 主菜单、战斗场景、暂停菜单、升级三选一、失败/胜利结算
- 玩家移动、鼠标瞄准、射击、生命、闪避
- 武器：AR-07 突击步枪、SG-12 霰弹枪、SR-09 精准步枪
- 敌人：近战追击者、远程射手、快速突袭者、精英、Boss
- 经验碎片、等级、随机三选一升级、升级实际生效
- 固定竞技场、墙体碰撞、摄像机跟随
- 波次、Boss、结算、重开
- Windows 测试构建与验收文档

## 操作
WASD 移动；鼠标瞄准；鼠标左键射击；Space 闪避；R 装弹（若实现弹匣）；1/2 切枪；Q 主动技能；Esc 暂停。

## 建议初始数值
玩家生命 100、移动速度 5、闪避冷却 2.5 秒、闪避持续 0.18 秒。
AR-07：伤害 12、射速 7 发/秒、弹匣 28、装弹 1.2 秒、散布 2 度。
SG-12：6 颗弹丸、每颗伤害 5、射速 1.1 发/秒、弹匣 6、装弹 1.5 秒、散布 22 度。
SR-09：伤害 45、射速 1.2 发/秒、弹匣 8、装弹 1.6 秒、穿透 2 个目标。
近战敌人生命 35、速度 2.3、接触伤害 10、攻击间隔 1 秒。
远程敌人生命 25、速度 1.5、攻击距离 6、投射物伤害 8、射击间隔 1.8 秒。
快速敌人生命 18、速度 3.4、接触伤害 8。精英生命 240，Boss 生命 900。
首局目标 10–15 分钟；需要通过试玩调整。

## 升级池
快速供弹、穿甲弹、高能弹头、战术翻滚、扩容弹匣、精准校准、电磁脉冲、生命补给、战斗专注。每项必须实际改变数值或战斗行为。
组合效果：火焰+穿透、电磁+高射速、冰霜+精准射击。首版可先用升级标签触发简单效果。

## 美术识别
主角：白发蓝眼成年女性战术角色，深蓝与冷白服装，青蓝能量细节。
主色：深海军蓝、冷白、青蓝；危险提示橙红。
战斗地面低对比；玩家子弹与敌方子弹颜色明显不同。
