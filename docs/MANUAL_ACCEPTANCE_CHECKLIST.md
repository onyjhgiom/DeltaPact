# 《三角洲契约 / DELTA PACT》人工验收清单
### 自动化冒烟测试（`-moriSmoke`，一波 5 秒 + Boss 测试无敌）无法覆盖的项，全部需真人在默认难度下实测。

> **运行方式**：双击 `C:\UnityProjects\MoriEchoes\PLAY_MoriEchoes.cmd`（720p 窗口）。
> **判定原则**：以下任一项不通过，记录现象（截图/录屏/文字）反馈给开发者，由人工调参或改代码，不得用自动测试结果替代。

---

## A. 默认难度完整通关（核心验收）
- [ ] 不借助测试无敌，从第一关打到最终 BOSS 击杀，过程未卡死/未崩
- [ ] 默认十波（非临时配置）节奏合理：刷怪密度、补给（血包/弹药掉落）足以支撑通关
- [ ] 死亡回到检查点后状态正确恢复（血量/弹药/位置）
- [ ] 通关结算（S/A/B/C 评级 + 用时 + 死亡数）正常弹出并可重开

## B. 真人鼠标长时手感（≥30 分钟连续游玩）
- [ ] 鼠标转向灵敏度适中（不过敏/不迟钝），长时间不累
- [ ] 三档视角切换（远景/越肩/开镜 Tab）无跳变、无黑边撕裂
- [ ] 八向瞄准（上/下/斜）在站立与下蹲时手感一致
- [ ] 跳跃手感：Coyote Time（离台可跳）、Jump Buffer（落地前预输入）、可变跳高符合直觉
- [ ] 闪避（翻滚）无敌帧时长合理，冷却不憋屈

## C. 实体手柄长时间实测
- [ ] 识别手柄（Xbox/PS）即插即用，按键映射正确（左摇杆移动/右摇杆瞄准/A 跳/B 闪避/RT 射/LT 开镜）
- [ ] 摇杆死区与灵敏度在长时游玩中无漂移
- [ ] 手柄振动反馈到位（开火/受击/击杀）

## D. 失焦 / 多显示器操作
- [ ] 切到另一窗口再切回，游戏不卡输入、不丢按键状态
- [ ] 主窗口在副显示器全屏/窗口运行时，鼠标坐标与瞄准一致（无偏移）
- [ ] Alt+Tab 后音频不堆叠、不爆音

## E. 音效听感
- [ ] 枪声/受击/击杀/技能/UI 各音效区分清晰，主音量（`masterVolume`）调节有效
- [ ] 长时间游玩无音频爆音、无重复音轨叠加
- [ ] Boss 阶段切换有音乐分层或音效提示

## F. 帧率 / 长时性能（建议配合性能 HUD）
- [ ] 默认 720p 单机关卡稳定 ≥ 目标帧率（建议 60）
- [ ] 同屏大量敌人/弹幕/Boss 弹幕峰值不掉帧严重
- [ ] 连续游玩 30 分钟内存不持续上涨（无泄漏）
- [ ] 加载关卡无明显卡顿/长时间黑屏

## G. 跨电脑兼容性
- [ ] 在另一台不同显卡/不同分辨率电脑上可启动并正常运行
- [ ] 不同 DPI 缩放（125% / 150%）下 UI 不溢出/不重叠

## H. 非 16:9 分辨率布局
- [ ] 16:10 / 21:9 超宽屏下 HUD（血量/弹药/技能/击杀信息）不被裁切
- [ ] 竖屏或窄屏有兜底（黑边或重排），不崩

## I. 美术与表现（对照参考图 / 《和平精英》）
- [ ] 程序化占位阶段：角色/敌人/场景可辨识、配色统一（青=友/橙红=敌/墨黑=底）
- [ ] 接入正式素材后：角色有清晰轮廓与动作表现，场景有层次与主题辨识度
- [ ] 特效（枪口/命中/击杀/技能）不喧宾夺主、不糊成一团

## J. 平衡性（人工主观 + 数据）
- [ ] 四角色差异化体验明显但无明显强弱失衡
- [ ] 敌人/Boss 难度曲线平滑，无"数值墙"
- [ ] 武器三选（AR/SG/SR）各有适用场景，无废枪

---

## 性能 HUD 建议（开发者侧埋点，便于 F/I/G 量化）
在 `HUDController` 加一个可开关的调试叠层（默认 `F3` 切换），显示：
- 实时 FPS + 帧时间（ms）
- 内存占用（Total Reserved）+ GC 次数
- 同屏敌人/弹幕计数
- 绘制调用（Batches）
配合此清单的 F/I/G 项，可在任意机器量化性能，无需专业工具。
