# 《三角洲契约》全面优化与新增建议（分五类）

> 基于当前仓库代码实际状态复核（`GameConfig` / `CharacterDefinition` / `CharacterSkill` / `WeaponController` / `ThemeProfile` / `EnemyRoster` / `SideEnemyMotor` / `RunModel` / `WeaponCapsuleDirector` / 本次新加的软推进与连击系统）。
> 每条含：**理由 · 预期效果 · 优先级（高/中/低）**。

---

## 现状速览（建议的事实基础）

- **角色**：4 名（DELTA 均衡 / VANGUARD 重装 / WRAITH 二段跳 / HAVOC 爆破），每人有 Q 技能 + F/C 技巧 + X 能量终结技 + 专精武器（+12%）。
- **武器**：**只定义了 3 把**（AR-07 突击 / SG-12 霰弹 / SR-09 精准），但引擎支持 6 把（`SwitchWeapon` 1–6、`weaponViewSprites` 6 槽），且 `CharacterSkill.Mastery` 引用第 3/4/5 把 → **专精有一半失效**。
- **场景**：5 主题（城市废墟·破碎者 / 工厂蜂巢·熔核 / 寒峰隧道·霜牙 / 未来都市·零点 / 最终要塞·终末回响），各有专属机关。
- **敌人**：5 关 × 4 兵种 = 20 原型，11 种攻击模式，含盾卫减伤、维修机修炮塔、飞行编队。
- **升级**：9 种 roguelite（射速/穿透/伤害/闪避/弹匣/精准/脉冲/生命/专注），升级三选一。
- **本次新增**：软推进（解除硬门）+ 连击/风格评分。

## 1）人物（角色外观 / 技能 / 改进 / 新角色创意）

| # | 建议 | 理由 | 预期效果 | 优先级 |
|---|---|---|---|---|
| 1.1 | **角色剪影差异化** | 现 4 角色靠 `accent/hair` 配色区分，但体型 `build`（0.92–1.15）差异太小、程序化占位下远看几乎一样 | 一眼认出角色 → 提升选择欲与身份认同（00 后吃"为喜欢的角色投入"） | **高** |
| 1.2 | **技能从"同质冷却"改为"非对称机制"** | 现 4 人 Q 都是"按了出个效果+冷却"，玩法差异感弱 | 给每人一个改变操作手感的机制（见下）→ 重玩不同角色像换游戏 | **高** |
| 1.3 | 角色机制创意：VANGUARD 加**被动受击减伤**；WRAITH 加**空中冲刺**（利用既有 `doubleJump` 扩成 dash）；HAVOC 加**跳雷**（脱手延时雷）；DELTA 加**短时子弹时间** | 4 人现仅数值差异（health/speed/magazine），缺"独有动作" | 操作深度↑，高手有钻研空间 | **高** |
| 1.4 | **新角色：RECON / 幻影射手**——短暂隐身（敌人失去目标）+ 狙击专精 | 现有 4 人无"隐身/潜行"向，缺战术位 | 提供"苟着打"流派，丰富阵容 | 中 |
| 1.5 | **新角色：MEDIC / 战地医师**——治疗光环 + 救人加速 | 为未来双人合作（见玩法）铺垫团队位 | 双人协同感，延长合作寿命 | 中 |
| 1.6 | **新角色：JUGGERNAUT / 冲锋者**——冲撞击退，把敌人撞下平台 | 利用 `SideEnemyMotor` 的重力+掉落即死（`body.position.y<-8`） | "环境击杀"爽点，地形互动 | 中 |
| 1.7 | 涂装/皮肤扩展（S 评价已解锁"共鸣"配色，可再扩每角色 3–5 款） | 现仅 1 款解锁配色 | 收集与晒图动力 | 低 |

## 2）场景（现有优化方向 / 新场景构想）

| # | 建议 | 理由 | 预期效果 | 优先级 |
|---|---|---|---|---|
| 2.1 | **机关密度均衡化** | Stage0 只有"崩塌跳台+油桶"，比 Stage3/4（电梯+激光+全息墙）单薄 | 每关都有 2–3 个需跳/躲的记忆点 → 5 关体验方差收窄 | **高** |
| 2.2 | **动态环境事件**（让静态背景"活"起来） | 现背景是静态配色（sky/distance/structure），无生命力 | 重玩每次略不同，氛围沉浸↑ | **高** |
| 2.3 | 具体动态事件：寒峰**周期暴风雪**（视野遮蔽+风向推力，复用 `iceFrictionFactor` 思路）；工厂**警报**（传送带加速，改 `ConveyorSpeed`）；废墟**余震**（随机平台崩塌，`PlatformSurface.Crumbling` 已有） | 接口大多现成，只需触发器 | 主题机制从"静态地形"升级为"活的关卡" | 中 |
| 2.4 | **垂直/多层段落** | 现基本纯横向推进 | 电梯井爬升段 / 自由下落段（`SidePlayerMotor` 已支持重力）→ 横版节奏变化 | 中 |
| 2.5 | **新场景：移动载具段**（飞驰列车/车顶战斗，强制向前+风阻） | 魂斗罗经典"追车关"，现无强制移动段 | 高强度记忆点、名场面来源 | 中 |
| 2.6 | **新场景：水下基地**（低重力高跳+浮力+氧气条） | 现无流体关卡 | 全新手感（改 `gravityScale`/`jumpVelocity` 即可原型） | 中 |
| 2.7 | **新场景：虚空/异次元**（重力反转、镜像房间） | 终局前的"规则打破"关 | 制造"这游戏还能这样"的惊喜 | 低 |
| 2.8 | 视差背景层 + 天气粒子（`distance`/`sky` 已有色板，加多层滚动与粒子） | 视觉深度不足 | 截图/切片更好看，利于传播 | 低 |

## 3）装备（属性 / 获取方式 / 稀有度体系）

| # | 建议 | 理由 | 预期效果 | 优先级 |
|---|---|---|---|---|
| 3.1 | **补齐第 4–6 把武器（修复失效专精）** | `Mastery` 引用武器索引 3/4/5，但 `GameConfig.weapons` 只有 3 把 → 角色专精 +12% 一半永远触发不了（如 DELTA 专精 0/3，3 不存在） | 专精真正生效，武器数翻倍 | **高** |
| 3.2 | 建议补：④**LMG 机枪**（高射速大弹匣低单发，对应 Mastery char2 的 2/4）；⑤**GL 榴弹**（用现成的 `explosionRadius` 字段，目前全 0）；⑥**RL 火箭筒**（高伤爆炸，`targetsPerBullet` 高穿透） | 字段全在（`explosionRadius` 一直没用上） | 武器手感矩阵完整：连射/范围/爆发/穿透 | **高** |
| 3.3 | **稀有度体系**（普通/精良/稀有/史诗）+ 词缀 | 现武器固定 3 把、胶囊固定几种，无刷取梯度 | 刷取动力、roguelite 深度↑ | **高** |
| 3.4 | 词缀示例：炽热(燃烧持续伤)、疾风(射速)、贯穿(穿透+)、暴烈(爆炸)、吸血(击杀回血) | 复用 `RunStats`/`WeaponDefinition` 字段 | 同名武器不同构筑 → 重复刷不腻 | 中 |
| 3.5 | **获取方式扩展**：胶囊是限时的，加"**武器箱**"（精英/密道必掉，永久换本局武器）+"**图纸**"（集齐解锁新武器进池） | 现只有限时胶囊，无永久获取 | 收集感 + 局内成长感 | 中 |
| 3.6 | **升级从纯数值扩到"改玩法"**：现有 9 种全是数值（射速/伤害/弹匣…）。加：子弹反弹、击杀回血、跳跃射击强化、暴击连锁、背刺加成 | 纯数值三选一"选择感"弱 | 构筑流派成型（暴击流/吸血流/跳射流） | 中 |
| 3.7 | 装备外观随稀有度变色/发光（`WeaponDefinition.color` 已有） | 现武器颜色固定 | 捡到稀有货一眼即知的爽感 | 低 |

## 4）玩法（核心优化 / 新模式 / 新机制）

| # | 建议 | 理由 | 预期效果 | 优先级 |
|---|---|---|---|---|
| 4.1 | **连击倍率接入实战**（本次已加连击但 `StyleMultiplier` 只显示未生效） | 连击目前只是数字 | 连击越高→能量充能越快（喂 X 终结技）或伤害微增 → "连击→攒大→放大→再连击"正反馈 | **高** |
| 4.2 | **突变器 / 每日挑战**（低重力 / 敌人爆炸 / 仅近战 / 双倍能量，每日种子固定组合） | 现一局永远一样 | 重玩发动机、分享"阴间图" | **高** |
| 4.3 | **风格分计入 S 评级**（`CampaignProgress.Grade` 现只看 死亡/时间/击杀） | "打得秀"不影响结算 | 鼓励激进华丽打法，S 更稀有 | 中 |
| 4.4 | **新模式：无尽模式**（波次生存，复用 `WaveManager` 已有逻辑） | 现仅固定 5 段+Boss | 长线留存、冲榜 | 中 |
| 4.5 | **新模式：Boss Rush**（连打 5 个 Boss，跳过关卡） | Boss 已有三阶段+处决窗，很成熟 | 练习+表演模式，切片素材 | 中 |
| 4.6 | **新模式：计时挑战 / 速通**（每关最速榜，配合幽灵） | 现无竞速 | 硬核玩家复玩 | 中 |
| 4.7 | **双人本地合作**（第二 `SidePlayerMotor`+双输入+倒地救援） | 魂斗罗灵魂，现单人 | 社交/同屏开黑，粘性最强 | 中 |
| 4.8 | **密道奖励强化**（`SecretBranchDirector` 已存在，加更明显的"高风险高回报"） | 密道存在感可再放大 | 探索回报感 | 中 |
| 4.9 | 成就 / 图鉴系统（敌人图鉴、武器图鉴、名场面回放） | 无收集闭环 | 长线目标、谈资 | 低 |

## 5）敌人（类型 / AI 行为 / 难度曲线）

| # | 建议 | 理由 | 预期效果 | 优先级 |
|---|---|---|---|---|
| 5.1 | **难度曲线段内递进**（现每关内密度恒定，张力前松后紧） | `SideEnemyMotor`/encounter 一段一刷，缺乏"渐强" | 每段敌人数量/混合度递增，Boss 前小高潮 → 张力曲线 | **高** |
| 5.2 | **AI 协作扩展**（现仅"维修机修炮塔"一种协同） | 敌兵大多各自为战 | 盾卫顶前+狙击殿后+编队夹击 → 逼迫玩家用策略而非硬刚 | **高** |
| 5.3 | 协作具体：盾卫（`ShieldRaised`）掩护后排狙击/激光；飞行编队（`Bomb/Dive`）与地面夹击同时段；精英仇恨转移 | 复用现有 `pattern` 与 `formation` | 战斗从"清杂兵"升级为"拆阵型" | 中 |
| 5.4 | **新敌人：自爆虫**（近身爆炸，`DangerArea`+延时引爆，逼走位） | 现无"逼你让位"的自爆单位 | 制造走位压力、配合软推进的"冲"更刺激 | **高** |
| 5.5 | **新敌人：干扰者**（短时禁用技能/遮蔽视野） | 现无"针对玩家能力"的敌人 | 迫使切换打法、增加紧张感 | 中 |
| 5.6 | **新敌人：召唤师**（召唤小怪，优先击杀目标） | 现无"母体"类单位 | 优先级决策（先杀召唤师）→ 战术层次 | 中 |
| 5.7 | **新敌人：隐形刺客**（隐身穿梭，显形瞬间重击，`Telegraph` 提示） | 现无潜行威胁 | 考验反应与预警识别 | 中 |
| 5.8 | **中段 mini-boss 加密**（`SecretMiniBossController` 已有，可在每关固定放一个非秘密的） | 现段落内缺少"小高潮" | 每关节奏起伏更明显 | 中 |
| 5.9 | **难度自适应**（按玩家血量/死亡数微调 `DamageScale` 与刷怪密度） | 固定难度易挫败新手 | 新手不被劝退、高手不被无聊 | 中 |
| 5.10 | 受击反馈分级（小怪击退/硬直，精英仅减速，Boss 无硬直） | 现反馈偏统一 | 打击感层次、重量感 | 低 |

## 建议的落地顺序（按"性价比"排）

**第一梯队（高优先 + 低风险 + 高杠杆，先做）**
- 4.1 连击倍率接入实战（本次已搭好架子，接上即可）
- 3.1 + 3.2 补齐武器 4–6（修复失效专精，字段全现成）
- 1.3 角色机制差异化（非对称手感）
- 5.4 自爆虫（配合软推进最爽）
- 5.1 难度曲线段内递进

**第二梯队（高优先，中等工作量）**
- 4.2 突变器/每日挑战
- 3.3 稀有度体系
- 2.1/2.2 机关密度 + 动态环境
- 5.2 AI 协作

**第三梯队（中优先，丰富长线）**
- 4.4–4.7 新模式（无尽/Boss Rush/速通/双人）
- 1.4–1.6 新角色
- 2.5/2.6 新场景（载具/水下）

> 说明：以上均建立在不破坏现有软推进、连击、胶囊、能量、密道、检查点、评级体系的前提下增量扩展。性能侧注意事项见 `PERFORMANCE_OPTIMIZATION_PLAN.md`；追平魂斗罗与超越魂斗罗的专项方案见 `PLAYABILITY_VS_CONTRA.md` / `PLAYABILITY_BEYOND_CONTRA.md` / `PLAYABILITY_OPTIMIZATION_DETAILED.md`。
