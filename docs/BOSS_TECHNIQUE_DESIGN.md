# 全十关 Boss 新增技能与美术规格

每关新增三招；第一、二、三形态各解锁一招，穿插于原有固定技能之间。攻击落点于释放时固定，不追着玩家移动；红色半透明范围与伤害判定一致。

以下为设计规格，实际生图、接入及测试状态以验收报告为准。每招对应图集一列，上格为释放图、下格为命中图。

## 第 1 关 · 城市废墟 / 破碎者

### 轨枕穿刺（形态 1 解锁）

释放方式：依次顶起三道短促地刺，位置释放前固定。

视觉表现：裂开的混凝土轨枕包裹钢刺，铜色碎屑沿斜面飞散。

闪避方法：离开三个红色落点，可跳过中间一刺。

素材：`Assets/Art/Production/BossTechniquesV1/stage-01/skill-1-release.png` 与 `skill-1-impact.png`。

### 钢索摆锤（形态 2 解锁）

释放方式：铆接重锤沿固定拱形轨迹横摆一次。

视觉表现：粗钢索、磨损铆钉与弯月状尘带，锤头保持实物轮廓。

闪避方法：从摆锤下方或轨迹外侧通过。

素材：`Assets/Art/Production/BossTechniquesV1/stage-01/skill-2-release.png` 与 `skill-2-impact.png`。

### 瓦砾折返（形态 3 解锁）

释放方式：两块装甲残片沿不同高度折返，留下中央通路。

视觉表现：扭曲钢板拖出细碎砂砾，蓝色液压断口点亮边缘。

闪避方法：观察两条路线，在中间高度换位。

素材：`Assets/Art/Production/BossTechniquesV1/stage-01/skill-3-release.png` 与 `skill-3-impact.png`。

## 第 2 关 · 工厂蜂巢 / 熔核

### 铸流分闸（形态 1 解锁）

释放方式：两道窄熔流交替开启，中央冷却带始终可通行。

视觉表现：铸铁闸嘴喷出黏稠熔浆，暗色氧化壳包住橙红内核。

闪避方法：进入中央间隔，避免熔流底座。

素材：`Assets/Art/Production/BossTechniquesV1/stage-02/skill-1-release.png` 与 `skill-1-impact.png`。

### 磁轨剪刀（形态 2 解锁）

释放方式：上下两根磁轨束斜向交叉，随后熄灭。

视觉表现：铁磁碎片围绕细窄翡翠束芯，交点只有短促铜色火星。

闪避方法：沿交叉轨道的外侧移动。

素材：`Assets/Art/Production/BossTechniquesV1/stage-02/skill-2-release.png` 与 `skill-2-impact.png`。

### 炉心跳火（形态 3 解锁）

释放方式：三枚炉渣团先后沿不同弧线跳跃。

视觉表现：半凝固熔壳、短尾焰和烟灰，落点生成熔裂花纹。

闪避方法：躲开固定弧线并利用两次落地之间的间隔。

素材：`Assets/Art/Production/BossTechniquesV1/stage-02/skill-3-release.png` 与 `skill-3-impact.png`。

## 第 3 关 · 寒峰隧道 / 霜牙

### 霜镜折射（形态 1 解锁）

释放方式：冰棱沿两段折线路线射入战区。

视觉表现：透明冰镜保留切面与内部裂纹，折射尾迹细而清楚。

闪避方法：穿过折线之间的空隙，避开拐点。

素材：`Assets/Art/Production/BossTechniquesV1/stage-03/skill-1-release.png` 与 `skill-1-impact.png`。

### 雪檐断坠（形态 2 解锁）

释放方式：四块雪檐按节奏坠落，最后一块延迟。

视觉表现：层积雪壳剥落成粉雪，深蓝冰芯完整可辨。

闪避方法：横向走出落点，不要提前回头。

素材：`Assets/Art/Production/BossTechniquesV1/stage-03/skill-2-release.png` 与 `skill-2-impact.png`。

### 零度花葬（形态 3 解锁）

释放方式：冰花环从外向内绽放，内圈短暂安全。

视觉表现：非对称冰瓣与细小霜晶逐层展开，不使用整屏白闪。

闪避方法：进入环中心或完全离开外缘。

素材：`Assets/Art/Production/BossTechniquesV1/stage-03/skill-3-release.png` 与 `skill-3-impact.png`。
