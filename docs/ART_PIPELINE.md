# 美术资产管线与提示词

## 统一风格
高品质日系动漫动作射击游戏美术，2D 手绘结合精致赛璐璐上色，末日科幻都市，深海军蓝、冷白与青蓝为主色，少量橙红表示危险，轮廓清晰、适合俯视角小尺寸游戏，统一光源与线条粗细。不要文字、水印、logo、UI 截图、拼贴边框、重复肢体或变形枪械。

## 主角立绘提示词
白发蓝眼的年轻成年女性战术士兵，未来科幻轻型战术服，深蓝与冷白装甲，青蓝发光能量模块，实用腰带与轻型护甲，手持原创科幻突击步枪，沉着坚定，日系动漫游戏角色概念设计，正面全身，纯色背景，不要文字和水印。此图用于概念设计，不要直接假定可作为动画 Sprite。

## 主角 Sprite 参考
同一白发蓝眼成年女性战术角色，深蓝冷白战术服，俯视角 2D 游戏 Sprite。分别单独输出朝上、朝下、朝左、朝右四张图；每张只出现一个角色，透明背景，比例和脚底基线一致，留 10% 安全边距。不要拼成 Sprite Sheet，不要文字、水印或背景。动画需人工修整以保证帧间一致。

## 武器提示词
分别单独生成原创虚构科幻枪械，侧视图，枪口朝右，透明背景，2D 手绘动漫风，清晰轮廓，适合 128–256 px 图标：
- AR-07：紧凑均衡型突击步枪，冷白机匣、深蓝握把、青蓝灯条。
- SG-12：短枪管厚实霰弹枪，橙色警示细节。
- SR-09：细长精准步枪，瞄准镜与青蓝标记。
禁止文字、厂牌、logo、水印。

## 敌人提示词
分别单独生成透明背景单体：近战追击者（低矮装甲、橙红弱点灯）；远程射手（紫红瞄准灯）；快速突袭者（轻型、低重心、速度感强）；精英（较大体型、蓄能部位明显）；Boss（普通敌人 2–3 倍、红色能量核心）。不需要血条、文字或背景。

## 场景提示词
俯视角正交 2D 手绘末日都市地面，破损沥青、混凝土裂缝、少量青蓝残光，低对比、无透视、可无缝平铺，不包含角色、车辆主体、UI 或文字。墙体、废车、路障分别独立生成透明素材。

## 特效提示词
每张独立透明 PNG：青蓝枪口火光、橙色命中火花、蓝白子弹轨迹、紫色电磁脉冲圆环、冰霜碎片、小范围火焰爆炸、受击闪光。每张只含一个特效，不要遮挡敌人轮廓。

## UI 图标提示词
深海军蓝半透明面板、冷白文字、青蓝强调、橙红危险状态，统一线宽。分别生成生命、经验、弹药、装弹、闪避、技能、暂停、波次、Boss、升级图标。不要文字与水印。

## Unity 导入建议
- Sprite，非像素素材 Filter Mode: Bilinear；Pixels Per Unit 按统一角色高度设置（例如 100）。
- Sprite Sheet 先确认帧格尺寸和排列再切片。
- 地面 Tilemap 必须实际检查边缘是否无缝。
- 保留原图、裁切图、提示词和来源/许可记录。
