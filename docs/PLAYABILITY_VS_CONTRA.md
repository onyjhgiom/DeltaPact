# 《三角洲契约 / DELTA PACT》可玩性 vs 《魂斗罗》对比与优化方案

> 适用对象：Codex / 后续制作。本文所有判断均基于当前仓库实际代码（`SidePlayerMotor.cs` / `LevelManager.cs` / `SideEnemyMotor.cs` / `SideBossController.cs` / `ExperienceManager.cs`），非空谈。
> 结论先行：**本作移动手感、Boss 系统、可读性（预警/危险区）已达标；可玩性短板集中在「节奏（推进模型）」「主题多样性（机制未落地）」「瞬时火力爽点（掉落胶囊缺失）」「敌人/关卡设计语言（缺乏跳/躲动机）」四方面。**

## 1. 逐维度对比表

| 维度 | 《魂斗罗》 | 当前《三角洲契约》 | 差距 |
|---|---|---|---|
| **核心循环** | 向右持续推进 = 逃避弹幕，前进即收益 | 段落式"封锁门"，清空敌人才放行（`LevelManager` GateLocked） | **致命差距**：失去"冲"的爽感 |
| **关卡多样性** | 丛林/基地/水面/雪原/外星，每关机制不同 | 主题*几何/机关*已落地（崩塌/冰面/传送带/电梯/激光/油桶），但*敌兵阵容行为*各关相同 | **中等差距**：战斗同质化 |
| **火力爽点** | 掉落武器胶囊（S 散弹/M 机枪/L 激光），捡到即强、限时 10s | 武器变化绑在 roguelite 升级（慢变量），无掉落胶囊 | **重大差距**：缺瞬时 dopamine |
| **敌人设计** | 炮塔、飞行编队、狙击、地刺逼跳、可破坏掩体 | 仅 Chaser/Gunner/Elite/Runner 朝你移动+射击 | 中等差距：行为单一 |
| **关卡语言** | 必须跳的坑/落石/塌桥、垂直攀爬、载具 | 平地+平台，无强制跳/躲的机关 | 中等差距 |
| **移动/瞄准** | 八向体瞄（跳起按住上斜射天花板） | twin-stick 鼠标/手柄独立瞄准，已支持手柄右摇杆 | 取舍项：更易上手，但少了"方向技巧" |
| **Boss** | 多阶段、可辨识招式 | 3 阶段+预警+弱点，已很强 | 基本持平，可保留 |

| **难度/重启** | 1–2 命、秒重生、短关 | 检查点+死亡重置，循环成立 | 持平 |

## 2. 为什么「可玩性不如魂斗罗」——根因拆解

### 根因 1：推进被封锁门打断（最致命）
`LevelManager.Update`（66–87 行）：玩家到达 `segment.start + 5` 触发 encounter，`GateLocked = encounter.Count > 0`，**必须清空敌人才解锁 Gate、才能继续向右**。这把游戏变成"逐房间站桩清场"，而魂斗罗的核心快感是"边冲边打、用前进甩开弹幕"。你现在的设计**惩罚了前进**——它强迫你停下来。

### 根因 2：主题"几何/机关"已落地，但"敌兵阵容与行为"不随主题变化（已更正）
> **更正（2026-10-25 复核 `SegmentBuilder.cs`）**：主题*几何/机关*其实已经实现——Stage1 崩塌平台+油桶、Stage2 传送带+液压冲柱+电磁门、Stage3 冰面+崩塌、Stage4/5 电梯、Stage4/5 激光栅栏+全息墙（`PlatformSurface` 崩塌逻辑、`StageHazard` 伤害均已写好）。详见 `PLAYABILITY_OPTIMIZATION_DETAILED.md` §0。
> 真正的差距缩小为：**敌兵阵容各关相同**——`BeginEncounter`（100–107 行）写死：
```csharp
EnemyKind kind = index == 0 ? EnemyKind.Chaser : index == 1 ? EnemyKind.Gunner
    : Stage > 1 && index == 2 ? EnemyKind.Elite : EnemyKind.Runner;
```
无论第几关都刷同种敌人，`ThemeProfile` 也只提供颜色 → 5 关**战斗体验**几乎一样，差异只在地形/机关。

### 根因 3：缺"掉落式武器胶囊"的瞬时爽点
`ExperienceManager` 的升级是**经验驱动的慢变量**（火力/冰冻/电磁脉冲）。魂斗罗 S 散弹的快感来自"跑过去踩到胶囊→立刻多管齐发"。本作没有"拾取即强、限时消失"的爆发型道具，火力成长曲线太平。

### 根因 4：敌人/关卡缺少"必须跳/必须躲"的设计语言
`SideEnemyMotor` 敌人行为是"朝玩家移动+瞄准射击"，没有：炮塔、飞行编队、地面落石/地刺逼跳、可破坏油桶（呼应 Stage1 燃烧油桶设定却未做）、掩体。魂斗罗的乐趣一半来自"看弹幕缝隙跳过去"。

## 3. 优化方案（按杠杆高低排序，可转交 Codex 直接施工）

### P0 —— 高杠杆、低风险，先做这三件

**P0-1｜解除硬封锁门 → 软推进**
- 改 `LevelManager.Update`：去掉 `GateLocked = encounter.Count > 0` 的硬卡死。改为"敌人从前方/右侧持续涌入，玩家向右移动即推进进度"，只有 **Boss 前**（最后一段）才硬锁。
- 具体：encounter 触发后不阻止越过 `segment.End`，但越过后旧敌兵自动退场；下一段在开始位置 +3 处预刷少量追兵，维持"被追着打"的压迫感。
- 收益：把"冲"的爽感还给玩家，单此一项就能显著拉近与魂斗罗的体感差距。

**P0-2｜加入掉落武器胶囊（S 散弹效应）**
- 复用 `PickupPool`，新增 `WeaponCapsule` 类型：敌人死亡有概率掉落、或藏在可破坏箱里；玩家踩到即切换为"散弹/机枪/激光"等价武器，**限时 10s 后消失**（魂斗罗经典）。
- 与现有 `WeaponController` 兼容：胶囊只覆盖"弹道形态"（扇形/连射/贯穿），不动弹药/换弹系统。
- 收益：制造瞬时火力爆发的 dopamine，这是可玩性提升最快的一招。

**P0-3｜敌兵阵容随主题变化（修正后的"主题差异化"）**
- 主题*几何/机关*已落地（见 §2 更正），此处只补**战斗阵容**：给 `LevelManager` 加每关招牌阵容表，`BeginEncounter` 按 `SelectedStage` 选敌（Stage1 多近战+飞行骚扰、Stage2 火力+冲锋、Stage3 飞行编队+冰面、Stage4 狙压+精英、Stage5 重装混编）。
- 收益：让"5 关打起来不一样"从口号变现实，多样性立刻上来。

### P1 —— 多样性与关卡语言

- **敌人扩展**：新增 `Turret`（固定炮塔，逼玩家走位）、`FlyerFormation`（编队俯冲）、`Snipers`（远处点射逼迫接近）；在 `SideEnemyMotor` 增加对应分支。
- **可破坏掩体/油桶**：`ProceduralArt` 画木箱/油桶，受击爆炸清场（呼应 Stage1 燃烧油桶设定）；掉落胶囊或经验。
- **强制跳/躲机关**：落石预警（`Telegraph` 已可用）、地刺周期、单向塌桥 —— 用 `StageHazard.cs` 落地。
- **垂直段**：`SegmentBuilder` 支持 `vertical` 段（攀爬电梯/竖井），打破纯横向。

### P2 —— 体验上限

- **双人本地合作**：魂斗罗灵魂。需 `InputReader` 双设备、`SidePlayerMotor` 第二实例、`CameraRig` 取两人中点+zoom。
- **节奏密度**：提高单位时间敌兵密度与弹幕复杂度（P0-1 软推进后自然提升）。
- **记忆点 set-piece**：载具段、电梯段、Boss 前演出。
- **瞄准模式选项**：保留 twin-stick 易上手，额外提供"键盘八向体瞄"模式给硬核玩家（魂斗罗式跳射天花板敌人）。

## 4. 验收口径（P0 完成后）

- 玩家从起点到 Boss，全程**不被封锁门强制站桩**，能保持向右推进的节奏；
- 任意一关能捡到至少 1 种限时武器胶囊并即时生效；
- Stage1 / Stage3 除已落地的崩塌/冰面机关外，还能观察到与"主题敌兵阵容"相关的明显战斗差异；
- 用 720p 通关冒烟（`SideScrollerSmokeTest -moriStage1`）通过，且真人默认难度下可无明显卡顿。

> 注：本方案聚焦"可玩性/设计"，性能层优化见 `PERFORMANCE_OPTIMIZATION_PLAN.md`（已另立）。两文档可并行施工。
