# 《三角洲契约》游戏设计文档（GDD）
版本：0.1 | 状态：MVP 规格草案

## 1. 高概念
《三角洲契约》是一款 2D 俯视角动漫风动作射击 Roguelite。玩家操控白发蓝眼的战术少女，在末日废墟中清理敌潮、拾取经验、选择随机升级并组合战斗能力。每局地图结构与升级选择带来不同的战斗构筑。

## 2. 视觉识别
- 主角：白发、蓝眼、未来战术服，轮廓清晰；避免过多细碎装饰影响小尺寸可读性。
- 主色：深海军蓝、冷白、青蓝能量色；危险提示使用橙红。
- 场景：末日都市、破损街道、遗迹、路障、废弃车辆；手绘质感但游戏内地面需低对比，不能干扰子弹识别。
- UI：深蓝半透明面板、清晰图标、有限的发光描边。
- 战斗反馈：枪口火光、命中闪白、少量镜头震动、清楚的受击音效。
- 目标：高辨识度、可读性优先，不以大量粒子覆盖整个屏幕。

## 3. 核心操作（PC）
- WASD：移动
- 鼠标：瞄准
- 鼠标左键：射击
- R：装弹（若当前阶段尚未实现弹匣，则此键先不启用）
- Space：闪避
- Q：主动技能（阶段 3 后实现）
- 1/2：切换主副武器（阶段 3 后实现）
- Esc：暂停

## 4. 摄像机与地图
- 俯视角正交摄像机。
- 玩家在屏幕中心附近移动，摄像机平滑跟随。
- MVP 采用一张固定竞技场，不做程序化地图生成。
- 使用 Tilemap 或模块化精灵铺设地面；墙体和大型障碍需配置碰撞体。
- 参考画布 1920×1080，UI 需使用 Canvas Scaler 和锚点适配其他分辨率。

## 5. MVP 内容
### 玩家
- 1 个可控角色
- 移动、朝向、瞄准、射击、闪避
- 生命值、受伤、死亡与重开
- 先使用占位 Sprite；美术资产导入后替换

### 武器
1. AR-07 突击步枪：均衡射速、伤害、散布。
2. SG-12 霰弹枪：近距离多弹丸，射速较慢。
3. SR-09 精准步枪：低射速、高伤害、有限穿透。
首版可以先只完整实现 AR-07，再抽象武器数据并扩展其余两种。

### 敌人
1. 近战追击者：追向玩家，进入距离后攻击。
2. 远程射手：保持距离并发射可见投射物。
3. 快速突袭者：生命较低、移动快、近身造成伤害。
4. 精英敌人：基础敌人强化版本，攻击预警更明显。
5. Boss：一阶段，至少两种可辨认攻击模式。

### Roguelite
- 击败敌人掉落经验碎片。
- 经验达到阈值时暂停战斗并显示 3 个随机升级。
- 升级池 9 项：快速供弹、穿甲弹、高能弹头、战术翻滚、扩容弹匣、精准校准、电磁脉冲、生命补给、战斗专注。
- 3 个组合效果：火焰+穿透、电磁+高射速、冰霜+精准射击。MVP 可先以“升级标签组合”实现，不要求复杂技能树。

### UI
- 主菜单：开始、设置、退出。
- 战斗 HUD：生命、经验/等级、波次、武器/弹药、技能冷却。
- 升级选择：三张卡片，显示名称、图标、描述。
- 暂停菜单：继续、重新开始、返回主菜单。
- 结算：胜利/失败、击败数量、用时、重新开始。

## 6. 核心循环
进入竞技场 → 消灭敌人 → 获得经验 → 触发三选一升级 → 敌人波次增强 → 精英/Boss → 结算 → 再次挑战。

## 7. 设计原则
- 每次升级都必须有可感知的战斗变化。
- 敌人攻击必须有预警，玩家应能理解自己为什么受伤。
- 玩家子弹、敌方子弹、经验拾取物要有明显颜色差异。
- UI 不遮挡主要战斗区域。
- 首版不做在线联机、抽卡、商城、开放世界、剧情配音、云存档。
