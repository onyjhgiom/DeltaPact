# 《三角洲契约》年轻化（00 后）吸引力方案

> 配套：`PLAYABILITY_VS_CONTRA.md`（追平）、`PLAYABILITY_OPTIMIZATION_DETAILED.md`（P0 落地）、`PLAYABILITY_BEYOND_CONTRA.md`（超越魂斗罗的 8 系统）、`PERFORMANCE_OPTIMIZATION_PLAN.md`（性能）。
> 本文聚焦一个独立维度：**让当下的 00 后（16–26 岁）愿意下载、愿意晒、愿意每天回来**。它和"追平/超越"正交，可并行。

---

## 0. 00 后的游戏口味画像（设计前提）

从当下爆款（原神/王者/三角洲行动/蛋仔/Phigros/抖音小游戏）倒推，00 后玩家最吃这几样，且彼此独立：

1. **短局 + 即开即走**：通勤/课间 3–5 分钟一局，不接受"不肝就废"。
2. **能整活 / 名场面**：要"这操作我能截下来发群里"的高光瞬间，不是纯粹数值碾压。
3. **能晒 / 有社交货币**：成就、皮肤、排行、分享卡，是社交谈资。
4. **身份认同 / 角色羁绊**：愿意为"喜欢的角色"投入（原神式人格化）。
5. **赛季目标 / 每日任务**：轻量、可跳过的持续进度，制造"明天再来"。
6. **梗 / 幽默 / 彩蛋**：自嘲、玩梗、整活，比"严肃军事"更对味。
7. **低压力竞争**：有排行但不强制，输赢都能发个表情包。

> 你的游戏底子其实很贴：2D 横版 + 快节奏 + 4 角色人格 + 可程序化生成美术（便于做皮肤/涂装）。下面把上述 7 点落成系统，**每条都标注它建在现有代码的哪块地基上**。

---

## A. 自动高光 / 名场面系统（Auto-Highlight）—— 最强的"晒"引擎

### 为什么抓 00 后
抖音/快手的游戏内容 90% 是"名场面切片"，不是全程直播。给每局自动抓 3 个最秀瞬间，结算页直接生成**可转发卡片**，传播自驱。

### 现有地基
- `GameManager` 已追踪 `Kills / Elapsed / Difficulty`。
- B2 连击（`Combo`）、B1 终结技（`TryUltimate`）、B7 Boss 处决（`Execute`）——这些都是现成的"高光事件源"。
- `CombatEffects` 有飘字通道；`ScreenCapture` 是 Unity 内置。

### 实现草图
```csharp
// 新增 HighlightTracker（挂 GameManager）
public struct Moment { public float at; public string tag; public int weight; }
private readonly List<Moment> moments = new();
void Mark(string tag, int weight) { /* 去重窗口 0.4s，取权重最高 */ moments.Add(new(){at=Elapsed,tag,weight}); }

// 事件挂点：
// - B2 连击 Combo>=8 时 Mark("连段 x"+Combo, Combo)
// - B1 放终结技 Mark("ULTIMATE", 100)
// - B7 Boss 处决 Mark("处决", 120)
// - 1.5s 内 3 杀 Mark("三连杀", 60)
// - 无伤推进 20s 且击杀>=5 Mark("无伤穿越", 50)

// 结算：选权重前 3 的瞬间，ScreenCapture.CaptureScreenshotAsTexture 在该 at 回放（或只存时间点由玩家回看）
// 生成分享卡：角色立绘(CampaignProgress 已有 Palette) + 本局数据 + 高光标签 → 存图到 PersistentDataPath
```
### 验收
- 一局结束出 1–3 张高光卡；卡面含角色+数据+标签；可一键存图转发。

## B. 表情 / 嘲讽 / 喷涂（Emotes / Taunts / Spray）—— 整活与社交货币

### 为什么抓 00 后
"发个表情""墙上喷个涂鸦"是零成本的自我表达与玩梗，Apex/Valorant 的 ping 与喷漆系统证明了它的黏性。

### 现有地基
- `SideCharacterVisual`（角色部件渲染）已存在 → 加 emote pose 状态。
- `ProceduralArt` 能在运行时生成纹理 → 喷涂用其生成的 graffiti 贴花。
- `HUDController.Announce` 已有提示通道。

### 实现草图
- 新增 `InputReader.Emote`（键 `T`/手柄 `Dpad`），呼出 4–6 格表情轮盘。
- 表情：挥手/指点/跳舞/敬礼/蹲嘲/喷漆。每个角色 2 个专属 + 通用 4 个。
- 喷漆：`ProceduralArt.Graffiti(seed, color)` 生成 64×64 贴图，贴到最近墙面（`OverlapArea` 找墙），保留 30s。
- 死亡/处决后可触发角色专属嘲讽动作（复用 `SideCharacterVisual` 部件动画）。

### 验收
- 按键出表情轮盘并播放角色 pose；喷漆落地成可消失贴花；不干扰战斗。

---

## C. 皮肤 / 涂装工坊 + 赛季通行证（Cosmetics + Battle Pass）—— 留存发动机

### 为什么抓 00 后
这是 00 后付费/回流第一驱动力（原神/王者/三角洲行动本身体证）。**免费线也必须有东西拿**，否则劝退。

### 现有地基
- `CampaignProgress.Write("Palette."+char, 1)` 已能存角色配色解锁 → 直接扩展为 `Skins[]` 解锁体系。
- `CharacterDefinition` 已有 `accent/hair/portrait/bodySprite` → 换色/换装就是改这些字段。
- `GameConfig.characters` 是数据驱动 → 皮肤表可并入。

### 实现草图
- **皮肤**：每个角色 3–5 款（默认/共鸣/S 评解锁/赛季限定/联动梗款），仅改 `accent/hair/bodySprite`，不影响数值。
- **赛季通行证**：新增 `BattlePass` 配置（赛季编号 + 50 级轨迹 + 每周任务）。免费线给皮肤碎片/配色，付费线给限定。
  ```csharp
  // MissionTracker（轻量，挂 GameManager）
  public void OnEvent(string id) { /* 匹配 weekly/daily 任务进度 */ }
  // 击杀/连击/用某角色通关/无伤段 → 调用 OnEvent
  ```
- 任务强调"好玩"而非"肝"：如"用 WRAITH 传送躲过 3 次狙击""单局触发 2 次处决"。

### 验收
- 皮肤可在角色页切换并实时预览；通行证经验随对局累积；每周任务可完成。

## D. 梗化成就 + 社交分享卡（Meme Achievements）—— 谈资制造机

### 为什么抓 00 后
成就名要"能当梗发"，不是"通关第 3 关"。成就感 × 幽默 = 自发传播。

### 现有地基
- `CampaignProgress.Write/Read` 已做解锁存储。
- A 系统的分享卡生成可复用。

### 实现草图（示例成就，命名走 00 后语境）
| 成就 | 触发 | 梗点 |
|---|---|---|
| 「这都能躲？」 | 残血(<10%)下闪避躲狙击 | 反差爽 |
| 「魂斗罗：余晖」 | 单局 S 评价 | 玩梗本体 |
| 「电梯惊魂」 | Stage4 电梯段无伤 | 场景梗 |
| 「油桶艺术家」 | 单桶连锁炸 8 敌 | 整活 |
| 「已读乱回」 | 用错胶囊融合翻车仍通关 | 自嘲 |
| 「阴间图幸存者」 | 带 2 个突变器通关 | 挑战梗 |
- 解锁即弹**分享卡**（角色+成就名+一句吐槽文案），一键存图。

### 验收
- 6+ 个梗成就可触发并存储；解锁弹卡可分享。

## E. 全球 / 好友排行榜 + 幽灵对战（Leaderboard + Ghost）—— 低压力竞争

### 为什么抓 00 后
有榜就有"下次冲更高"，但**不强制**实时对抗，契合低压力竞争。幽灵对战把"单人"变成"和别人的影子比"。

### 现有地基
- `GameManager` 全量数据、`LevelManager.Rating` 评分、`Elapsed` 计时均已就绪。
- B5 突变器已让"同图"可复现（同种子）。

### 实现草图
- **榜维度**：每关「最高分 / 最快通关 / 最高连击 / 最秀处决」。
- **幽灵**：通关时记录玩家位置轨迹（轻量采样 10Hz），下次同关生成半透明"影子"陪跑（仅本地即够爽，联网为加分项）。
- 联网榜为 P2；**先做本地榜 + 种子幽灵**，零后端可玩。

### 验收
- 单机关卡内显示历史最佳与幽灵；结算刷新本地榜。

## F. 突变器分享码（Mutator Share Codes）—— 把 B5 变社交病毒

### 为什么抓 00 后
"来我这个阴间图""这图你能过算我输"是强社交钩子。一串短码就能把好友拉进同一变态关卡。

### 现有地基
- B5 的 `Mutator[]` 枚举 → 编码成 4–6 位码（如 `DPA-7F3K`）即可。

### 实现草图
```csharp
string Encode(Mutator[] m) { /* 位掩码/哈希 → base32 短码 */ }
Mutator[] Decode(string code) { /* 校验和防误输 */ }
// 菜单"输入分享码" → 应用到本局突变器
```
### 验收
- 生成码可复制；好友输入同码进入相同突变组合；非法码提示。

## G. 角色人格化 / 语音 / 羁绊（Character Personality + Bond）—— 身份认同

### 为什么抓 00 后
原神/王者证明：玩家会为"人"付费和回流。4 角色目前只有名字和技能，缺**人格**。
（无需真配音资源也能做：立绘表情、台词文字、档案收集、好感度。）

### 现有地基
- `CharacterDefinition` 已有 `name/role/SkillName/SkillDescription` → 扩 `personality/quote/idleLine`。
- `SideCharacterVisual` 可加 idle 微动作。
- B8 双人合作 → 升级为「羁绊」：特定两人同队触发合体终结。

### 实现草图
- 每个角色加：一句登场台词、击杀俏皮话、死亡碎碎念、档案卡（背景故事 2 段）。
- **羁绊终结**：WRAITH+VANGUARD 同队 → 终结技变为"相位庇护"（传送护送 + 满血）；HAVOC+DELTA → "双爆轰"。在 B8 之上加一层组合技。
- 好感度（`CampaignProgress` 存）满级解锁专属涂装/台词——轻量养成。

### 验收
- 角色页有档案/台词；特定双人组合触发不同合体终结；不破坏单人平衡。

## H. 整活沙盒 / 游乐场模式（Chaos Sandbox）—— 纯爽 + 直播饵

### 为什么抓 00 后
给玩家一个"不扣分、随便炸"的房间：刷怪、放油桶、慢动作、自由镜头，专门用来整活和录切片。直播/短视频的素材工厂。

### 现有地基
- `EnemyAI` 生成、`StageInteractable.ConfigureBarrel`、B7 慢动作（`Time.timeScale`）全部现成。

### 实现草图
- 主菜单"游乐场"：可选敌人种类/数量、无限弹药、慢动作拨杆、自由镜头（WASD 移相机）。
- 所有击杀/爆炸照常触发 A 系统高光标记 → 一键存切片。
- 无评分、无失败，纯玩。

### 验收
- 进入沙盒可自由刷怪/调慢动作/录高光；退出不影响主线存档。

---

## I. 短局 + 抖音式挑战（Short Run / 15s Challenge）—— 拉新入口

### 为什么抓 00 后
新用户被"3 分钟一局"劝进，被"15 秒挑战"勾起胜负欲。是短视频投放的最佳承接页。

### 实现草图
- 主菜单"今日挑战"：每天一个变态小目标（"散弹 15s 清 20 敌""无伤过电梯段""单胶囊通关 Stage1"）。
- 计时 + 即出结果 + 高光卡 → 天然短视频素材。
- 复用 B5 突变器 + B1 终结技做花样。

### 验收
- 每日挑战可玩、计时结算、出卡；不参与主线评分。

## J. 直播观众互动（Streamer Interactivity，延展）—— 破圈钩子

### 为什么抓 00 后
B 站/抖音主播是 00 后游戏认知的第一入口。让观众决定下一关突变、投票掉胶囊，主播节目效果拉满。
（属 P2 延展，先做本地，联网为加分。）

## 落地优先级（年轻化漏斗）

把上述 10 项按"拉新 → 留存 → 传播 → 回流"串成漏斗，**每阶段挑 1–2 个先做**：

| 阶段 | 目标 | 优先系统 |
|---|---|---|
| **拉新** | 让人点开、点开就爽 | I 短局挑战 · A 自动高光 |
| **留存** | 每天想回来 | C 赛季通行证 · D 梗成就 · G 角色人格 |
| **传播** | 主动晒出去 | A 分享卡 · F 突变器分享码 · D 梗成就卡 · B 喷涂/表情 |
| **回流** | 明天还来 | C 每周任务 · E 幽灵/排行 · G 羁绊 · H 沙盒整活 |

**建议第一批（低成本高传播）**：A 自动高光 + D 梗成就 + F 分享码 + B 表情喷涂——这四件几乎不碰核心战斗，纯加在 UI/事件层，却能立刻让游戏"有得晒、有得玩梗"。
**第二批**：C 赛季 + G 人格羁绊 + E 排行幽灵。
**第三批**：H 沙盒 + I 每日挑战 + J 直播互动。

> 与前面方案的关系：A 吃 B1/B2/B7 的事件；F 吃 B5；G 的羁绊吃 B8；全部复用既有 `CampaignProgress`/`CombatEffects`/`ProceduralArt` 地基，不另起炉灶、不破坏 P0 追平与性能优化。
