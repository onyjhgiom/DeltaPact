## 一、V2EX（技术社区，重过程与诚实的限制）

**节点**：`创造分享` 或 `游戏开发`

**标题**：独立做了个 Unity 2D 横版射击 Roguelite，8 角色 10 关，放出 Windows 试玩包

**正文**：

> 业余时间用 Unity 6000.6.7f1 + C# 做了一个离线单机横版闯关射击 Roguelite，叫《末日回响 / DeltaPact》。现在放出 Windows x64 试玩包，想请各位帮忙看看手感和难度。
>
> 实际配置：
>
> - 8 名可选角色（DELTA / VANGUARD / WRAITH / HAVOC / KALT / VEIL / SERA / ROOK），每人 Q/F/C 三招 + X 终结技
> - 9 把武器，含激光刃；掉落胶囊切换强化形态
> - 10 关战役：前 5 关横版推进，6–8 关竖井攀升，第 9 关海面游泳，第 10 关水下浮沉（氧气 / 水压 / 热泉补氧）
> - 三阶段 Boss、30 招独立技能、红色预警追击、中段密室、检查点重试
> - Tab 切三档 2D 正交视角：战术远景 / 第三人称近景 / 第一人称武器前景
>
> 技术上：URP 2D + Input System，美术是生成式 2D 精灵与法线素材，本轮构建 0 错误 0 警告，同一最终 EXE 的五组 Player 回归共 1767 项通过。
>
> 代码与素材索引：https://github.com/onyjhgiom/DeltaPact
>
> Windows 试玩包（406MB，SHA-256 / CRC / 解压回读已校验）在 `Releases/MoriEchoes_20261119_233520/`，解压后运行 `START_GAME.cmd`。
>
> 想诚实说明的限制：这是 Development 试玩构建，不是正式版；跨机性能、真人默认难度平衡和实体手柄长测都还没做。自动测试能证明流程跑通，不能证明好玩。如果有人试玩后愿意说说「哪里无聊 / 哪里太难 / 操作哪里别扭」，对我帮助很大。

## 二、掘金（重工程拆解与可复现）

**标题**：从 0 手搓一个 Unity 2D 射击 Roguelite：10 关、8 角色、1767 项回归是怎么搭起来的

**标签**：`Unity` `游戏开发` `C#` `独立开发`

**正文**：

> 分享一个从玩法设计到打包分发全程独立完成的 Unity 2D 项目，重点讲工程做法和踩过的点，不只是晒图。
>
> **项目结构**
>
> - Unity 6000.6.7f1 / C# / URP 2D / Input System 1.20.0 / UGUI 2.6.0
> - 入口 `Assets/Scenes/MainMenu/MainMenu.unity`，GameBootstrap 绑定 `Assets/Settings/MoriEchoesConfig.asset`
> - 数据驱动：角色、武器、技能、关卡分别在数据文件里配置；30 招技能用形态 + 出招计数驱动测试覆盖
>
> **几个实现要点**
>
> 1. **三档 2D 正交视角**：Tab 在战术远景 / 第三人称近景 / 第一人称武器前景之间切换，但底层仍是 2D 横版规则，不改碰撞与输入。
> 2. **Boss 预警与追击**：蓄力时显示半透明红色落点 / 路径，新增技能提前约 0.8 秒锁定落点，锁定后不再黏着玩家；Boss 可越过障碍接近，远距离先提示再高速飞掠。
> 3. **四种推进方式**：横版推进、竖井攀升（上射穿单向平台）、海面游泳（浮动平台 + S+Space 下穿）、水下浮沉（全向阻尼 + 氧气 / 水压 + 热泉补氧）。
> 4. **测试策略**：合成输入 + 无敌 / 伤害 / 位置辅助，覆盖十关越障追击、实际伤害、锁定后闪避、残血不自动结束、最后一击与演出中的经验干扰；同一最终 EXE 五组回归共 1767 项通过，构建 0 错误 0 警告。
> 5. **打包与校验**：`Tools/Package-WindowsGame.py` 排除调试符号与 Unity 备份目录，产出 zip 后跑 CRC 与解压回读哈希，附 SHA-256 清单。
>
> **限制**：实体手柄、跨机性能、真人难度平衡和 Editor Play Mode 尚未验收；美术是开发期生成素材，不是最终商业稿。
>
> 仓库：https://github.com/onyjhgiom/DeltaPact
> README 里有画面预览、十关场景与小怪图鉴、素材来源表，想看效果可以直接翻。
